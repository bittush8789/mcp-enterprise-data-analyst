### Corporate DevOps CI/CD Pipeline | GitHub Actions, Docker, Kubernetes, AWS
- Designed and implemented an end-to-end CI/CD pipeline for a Java application using **GitHub Actions, Maven, Docker, and Kubernetes**.
- Automated **build, code-quality analysis, security scanning, containerization, and Kubernetes deployment** through GitHub Actions.
- Integrated **SonarQube** for static code analysis and quality gates, and **Trivy** for filesystem and Docker image vulnerability scanning.
- Containerized the application using **Docker** and automated image publishing to **Docker Hub** through the CI/CD pipeline.
- Deployed the application on **Kubernetes running on AWS EC2**, using Deployments, Services, and **RBAC** for controlled cluster access.
- Implemented **Prometheus and Grafana** for infrastructure and Kubernetes monitoring, providing operational visibility through dashboards.
- Configured a **self-hosted GitHub Actions runner** to execute CI/CD workloads and securely interact with the Kubernetes environment.

**Tech Stack:** AWS EC2, Linux, Git, GitHub Actions, Maven, Docker, Kubernetes, SonarQube, Trivy, Docker Hub, Prometheus, Grafana, RBAC
